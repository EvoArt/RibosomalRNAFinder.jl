API

RibosomalRNAFinder.RNAHit — Type
RNAHit

One predicted RNA. start:stop are 1-based inclusive coordinates on the input sequence seqid; strand is '+' or '-'. partial marks a hit shorter than lencutoff of the model length. bias is the composition-bias correction already subtracted from bits (computed only with scoring=:forward; else 0).

Hits with vector indexing and Tables.jl row access, plus the FASTA they came from.

RibosomalRNAFinder.findrna — Method
findrna(fasta; models=nothing, evalue=1e-6, reject=0.25, lencutoff=0.8,
        profiles=default_profiles(), threaded=true, progress)

Find rRNA genes on both strands of every sequence in fasta.

  • models: names of the profiles to search, e.g. ["16S_rRNA"] (default: all).
  • evalue: report hits with E-value at most this (barrnap's --evalue).
  • reject: drop hits shorter than this fraction of the model (--reject).
  • lencutoff: mark hits shorter than this fraction as partial (--lencutoff).
  • profiles: a HMMER3 nucleotide profile file, for other RNA families.
  • scoring: :viterbi (default, fastest) scores each gene by its best alignment. :forward rescores it as nhmmer (and so barrnap 0.9) does: Forward score with composition-bias correction and Forward-calibrated E-values, giving bits and E-values within about a bit of nhmmer's.

Further keywords (seed_bits, db_size) go to ProfileHMMs.scan_fasta. Returns an RNAResult: a vector of RNAHit and a Tables.jl table.

RibosomalRNAFinder.hit_ids — Method
hit_ids(r::RNAResult) -> Vector{String}

An identifier per hit, seqid:start-stop(strand), as written by write_fasta. With extract_sequences this gives the (sequences, ids) pair taken by AssignTaxonomy.assign_taxonomy.
